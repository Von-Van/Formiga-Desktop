FORMIGA — QUICK START

1. Drag Formiga into the Applications folder shown beside it.
2. Open Formiga from Applications. Settings opens automatically the first time.
3. Use the small Formiga menu-bar icon to show, pause, gather, check for updates, configure, or quit
   the colony.

This portfolio preview is unsigned. If macOS blocks the first launch, Control-click Formiga,
choose Open, then confirm Open. You only need to do this once. Do not disable Gatekeeper.

Formiga does not capture your screen, inspect window contents, record input, or upload colony data.
Its optional updater contacts only the public Formiga repository on GitHub; disable automatic checks
under Settings > About if desired.
