# itch.io page kit for Formiga

Everything below is ready to paste into a new itch.io project page. Nothing here is uploaded or
published automatically - it is copy and commands for the owner to use by hand, in a couple of
minutes, in itch's own dashboard.

## Suggested classification

- **Kind of project:** Downloadable (a native Windows/macOS app, not an HTML game - confirm the
  exact wording on itch's current page-creation form, since itch has renamed this field before).
- **Release platforms:** Windows, macOS. (Leave Linux, Android, and web unchecked - none are
  built today.)
- **Pricing:** owner's call; this kit assumes "Name your own price" with a $0 minimum, which is
  the common choice for a free, open-source desktop toy, but nothing here depends on it.
- **Tags** (itch tags are lowercase and hyphenated, similar to the GitHub topics in
  `packaging/REPOSITORY.md`, but curated for itch's audience and search):
  `desktop-toy`, `virtual-pet`, `pixel-art`, `procedural-generation`, `simulation`, `sandbox`,
  `relaxing`, `cute`, `ambient`, `companion`

## Page body copy

Paste everything between the rules into itch's page description editor.

---

Formiga is a tiny colony that lives on your desktop.

Drop it onto your screen and a handful of seeded, procedurally generated pixel creatures move
in - literally onto your desktop, in transparent windows that sit alongside your normal apps.
They perch on the tops of your real windows, ride them when you move things around, react to
your cursor, and slowly grow into a four-creature colony with a home of its own.

No two creatures are alike. Each one resolves from a 256-bit seed into its own body plan, ears,
tail, proportions, markings, palette, and personality, rasterized into its own sprite the moment
it's born. Pet them, drag them, watch them nap, snack, play, and occasionally strike up a
friendship - or a rivalry - with a neighbor.

**What your creatures get up to**

- Eleven expressions, natural blinking, and a gaze that actually follows what's nearby.
- Climbing, hopping between window ledges, riding windows as you move them, and squeezing
  through gaps that vanish the moment your desktop layout changes.
- Small, spontaneous games - chases, tag, tug-of-war, hide-and-seek across your own windows, and
  more - that any creature is free to decline.
- A colony home that grows into a small village as companions arrive, plus a journal and
  scrapbook that remember arrivals, discoveries, and keepsakes.
- A creature studio for previewing new arrivals, including turning your own PNG or JPEG into a
  cute (never exact) reinterpretation.

**Your privacy, plainly**

Formiga has no account system, no analytics, no ad SDK, and no cloud service. Creature
generation, simulation, artwork, and your save all stay on your computer. The only network
feature is an optional check for new releases at most once a day, and it can be switched off in
Settings. Formiga never inspects window contents, captures your screen, or logs keystrokes. Full
detail: [docs/PRIVACY.md](https://github.com/Von-Van/Formiga-Desktop/blob/main/docs/PRIVACY.md).

**Installing**

These builds are not code-signed yet, so your OS will flag them as coming from an unrecognized
developer the first time you open one - that's expected, not a sign anything is wrong.

- **macOS 14 or later:** download the `.dmg`, open it, and drag Formiga to Applications. The
  first time, Control-click the app and choose *Open*.
- **Windows 10/11 (64-bit):** download the `.msi` and run it - it adds normal Desktop and
  Start-menu shortcuts. If SmartScreen appears, choose *More info -> Run anyway*.

Every download is named after its release (for example `Formiga-0.58.7-macOS-universal.dmg`) and
ships with a matching `.sha256` file if you'd like to verify it yourself.

**System requirements**

- macOS 14 or later (Apple Silicon and Intel; one universal download)
- Windows 10 or 11, 64-bit
- A GPU capable of Metal / DirectX 12-class rendering - anything from the last several years

**Open source**

Formiga is MIT-licensed and developed in the open at
[github.com/Von-Van/Formiga-Desktop](https://github.com/Von-Van/Formiga-Desktop). Issues, ideas,
and pull requests are welcome there.

## Publishing the builds with butler

Run these after downloading the release assets you want to publish (or building them locally).
`<itch-user>` is a placeholder - substitute the owner's actual itch.io username, and run
`butler login` once beforehand (it opens a browser to authenticate; no API key ever needs to be
typed into a terminal or committed anywhere).

```sh
# macOS - the universal .dmg is the artifact the README already recommends to users.
butler push Formiga-0.58.7-macOS-universal.dmg <itch-user>/formiga:mac-universal --userversion 0.58.7

# Windows - the .msi, for the same reason (adds Desktop/Start-menu shortcuts).
butler push Formiga-0.58.7-windows-x64.msi <itch-user>/formiga:windows-x64 --userversion 0.58.7
```

Bump `--userversion` (and the filenames) for every new release; itch keeps each channel's
version history and lets installed copies auto-update through the itch app.

Optional: the release also publishes portable `.zip` builds for both platforms
(`Formiga-0.58.7-macOS-universal.zip`, `Formiga-0.58.7-windows-x64.zip`). They are not required,
but can be uploaded as extra files on the same page (via itch's web dashboard rather than
butler) for people who would rather not run an installer.
