FORMIGA — QUICK START

Double-click Formiga.exe. Settings opens automatically the first time, and a tiny creature moves
onto the desktop. Use the Formiga tray icon to show, pause, gather, check for updates, configure, or
quit the colony.

The MSI installer is recommended because it adds normal Desktop and Start-menu shortcuts. This
portable copy stores colony state in your regular per-user application-data folder, not beside the
executable.

This portfolio preview is unsigned. If SmartScreen appears, choose More info, then Run anyway.

Formiga does not capture your screen, inspect window contents, record input, or upload colony data.
Its optional updater contacts only the public Formiga repository on GitHub; disable automatic checks
under Settings > About if desired.
